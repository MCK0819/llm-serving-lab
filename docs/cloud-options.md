# 원격 GPU 배포 후보와 비용

조사일: 2026-09-09. 상태: 비교 자료 — 업체 선정·구매·배포 전.

## 쉽게 이해하기

GPU 가상머신은 컴퓨터를 빌려 직접 프로그램을 운영하는 방식이다. 관리형 GPU 컨테이너는 우리가 만든 실행 묶음(Docker 이미지)을 업체가 실행해주는 방식이다. 두 방식 모두 오픈소스 모델과 vLLM을 직접 설정할 수 있지만, 호스트와 네트워크를 제어할 수 있는 범위가 다르다.

## 후보 비교

| 후보 | 운영 형태 | 확인한 가격 예시 | 이번 프로젝트의 장점과 제약 |
|---|---|---|---|
| Runpod Pods, RTX A5000 24GB | 관리형 GPU 컨테이너 | 공식 공개 페이지 $0.27/시간 | 비용 우선 후보. 자체 vLLM 이미지를 배포할 수 있지만 Pod 안에서 Docker Compose는 지원되지 않는다. CPU 백엔드는 별도 서버의 Compose로 운영할 수 있다. |
| Lambda, 단일 A6000 48GB | GPU 가상머신 | 공식 1-GPU 표 $1.09/시간 | 직접 서버 운영 후보. SSH·방화벽·Docker 운영을 다루기 좋다. Runpod 후보와 GPU·메모리·CPU 구성이 다르므로 성능당 비용 비교 결과는 아니다. |
| AWS EC2 G5 | GPU 가상머신 | 리전별 확정 견적 미확보 | 클라우드 네트워크·권한·운영 구성을 함께 경험하는 후보. 실제 리전 요금과 계정 GPU 할당량·용량을 확인하기 전에는 비용 순위를 매기지 않는다. |

Runpod 요금 페이지에는 Community/Secure Cloud 선택이 있으므로 실제 생성 화면에서 선택한 등급·GPU·리전의 가격을 다시 확인해야 한다. 공개 가격이 지금 원하는 지역에서 대여 가능하다는 뜻은 아니다. 다른 업체도 실제 가용성은 확인하지 않았다.

## GPU 사용 시간에 따른 계산

공개 단가에 시간만 곱한 계산이다. 저장소·일반 서버·세금 등의 비용은 포함하지 않았다. GPU 시작 준비·모델 다운로드·워밍업·실험 준비 동안의 과금 시간도 총 사용 시간에 포함해야 한다.

| GPU 후보 | 총 20시간 | 총 40시간 |
|---|---:|---:|
| Runpod A5000, $0.27/시간 | $5.40 | $10.80 |
| Lambda A6000, $1.09/시간 | $21.80 | $43.60 |

40시간은 계획을 비교하기 위한 가정이며, 구현과 실험이 이 시간 안에 끝난다는 보장이 아니다. 하루 개발 4~5시간 전체를 GPU 실행 시간으로 사용할 필요는 없다.

## 전체 비용을 생각하는 예시

Runpod GPU를 40시간 사용하고, 50GB 네트워크 저장소를 한 달 유지하고, 별도 CPU 서버를 한 달 쓰는 예시다. 이것은 최종 배포 견적이 아니다.

| 항목 | 조건 | 계산 |
|---|---|---:|
| GPU | A5000, 40시간 | $10.80 |
| 모델용 네트워크 저장소 | 50GB × $0.07/GB/월 | $3.50 |
| CPU 서버 가격 참고 | Hetzner CX33 독일/핀란드, 월 상한, IPv4·VAT 제외 | $9.99 |
| 확인한 세 항목 소계 | 서로 다른 업체를 조합한 가격 예시 | **$24.29** |

소계에는 GPU 컨테이너 임시 디스크, IPv4, 별도 백업, 추가 트래픽, 세금, 환전·결제 수수료가 빠져 있다. 예를 들어 Runpod 컨테이너 디스크도 별도 과금 대상이다. 따라서 $24.29를 실제 최종 결제 금액이나 예산 상한으로 사용하지 않는다.

CPU 서버는 가격 참고일 뿐 선정하지 않았다. 임베딩·Worker·DB·모니터링을 함께 실행할 메모리와 CPU 여유를 확인해야 한다. CPU와 GPU 지역이 멀면 지연이 추가되므로 저렴한 서버를 서로 조합하는 것만으로 결정하지 않는다. 모델과 이미지에 충분한 디스크 공간인지도 확인해야 한다.

## 보안과 배포에서 확인할 조건

- Runpod은 Pod의 컨테이너 배포까지만 담당한다. 전체 시스템의 Compose 파일을 그대로 Pod에 실행할 수 있다고 가정하지 않는다.
- CPU와 GPU가 다른 업체에 있으면 같은 내부 네트워크라고 간주하지 않는다. 인증된 암호화 통신과 접근 제한을 구성해야 한다.
- Runpod의 SSH 접속 방식별 지원 범위를 확인하고 실제 터널 통신과 재연결을 검증하기 전에는 통신 설계가 완료되었다고 하지 않는다. 공개 HTTP 프록시 주소에 추론 서버를 그대로 노출하지 않는다.
- Lambda는 인바운드 방화벽 규칙을 지원한다. 방화벽만으로 통신 내용이 암호화되는 것은 아니므로 연결 보호를 별도로 구성한다.
- GPU를 중지·해제한 뒤에도 저장소가 남아 과금될 수 있다. 저장 방식별 데이터 유지 조건과 해제 절차를 기록한다.
- 부하 테스트에서는 네트워크 시간을 포함한 사용자 관측값과 vLLM 내부 처리 지표를 구분한다.

출처: [Runpod SSH](https://docs.runpod.io/pods/configuration/use-ssh), [Lambda 방화벽](https://docs.lambda.ai/public-cloud/firewalls/).

## 현재 판단과 다음 결정

비용 우선 후보는 Runpod A5000이다. 다만 안전한 원격 연결과 원하는 지역의 실제 대여 조건을 통과해야 선택한다. GPU 가상머신에서 Docker를 직접 운영하는 경험을 더 중시하면 Lambda 또는 AWS를 비교한다. 특정 업체를 사용한다는 사실만으로 실무 적합성이 결정되지는 않는다.

4주 전체 상한 10만 원, 지출 목표 6~8만 원으로 합의했다. 이 안에서 업체와 실행 환경을 선정한다.

## 2026-09-10 합의한 예산

**합의: 4주 지출 목표 6~8만 원, 전체 상한 10만 원.** 사용자가 예산 방향을 승인했다. 구매·충전·자원 생성은 수행하지 않았다. 상한 전액을 사용할 목표는 아니다. 2~4주 추가 연장 비용은 별도다.

### 계산 가정

- 저렴한 원격 GPU 컨테이너와 별도 일반 CPU 서버를 조합한다. AWS GPU 가상머신의 장시간 사용까지 포함한 범용 예산은 아니다.
- GPU 과금 시간은 처음에 총 40~60시간을 계획한다. 다운로드·모델 준비·환경 문제 해결 시간도 포함한다. 이 시간이 충분하다는 보장은 없으므로 남은 예산으로 실험 우선순위를 조정한다.
- 환산은 **예산 계산용 1달러=1,500원**으로 한다. 실제 현재 환율이나 카드 청구 환율을 인용한 값이 아니다.
- 2026-09-10 공개 페이지에서 Runpod A5000 $0.27/시간, L4 $0.49/시간을 다시 확인했다. 선택 등급·지역·가용성의 실제 단가는 대여 직전 확인한다. 실제 업체는 미선정이다.

### 항목별 배정안

| 항목 | 배정액 | 용도 |
|---|---:|---|
| GPU 대여 | 45,000원 | 초기 연동, 장애 재현, 부하와 재측정 |
| 일반 서버 | 30,000원 | API·Worker·DB·CPU 임베딩 등 실행 |
| 저장소와 부대 자원 | 10,000원 | 모델 저장소, 임시 디스크, IP, 작은 백업 등 |
| 세금·수수료·추가 실험 예비비 | 15,000원 | 실제 결제 차이와 예상하지 못한 비용 |
| 합의한 총액 상한 | **100,000원** | 항목 간 조정은 가능하되 총액을 기준으로 관리 |

일반 서버 3만 원 배정은 확정 견적이 아니다. 참고로 Hetzner CX43 독일/핀란드 월 상한은 공개 표상 $18.49로, 위 환산 가정에서 27,735원이다(IPv4·VAT 제외). 앞선 CX33 예시보다 자원 여유를 검토할 수 있도록 예산을 높였다. 실제 CPU·메모리·지역은 TEI와 DB 동시 실행에 맞게 확인한다.

GPU 60시간은 A5000 공개 단가 기준 24,300원, L4 기준 44,100원이다. 50GB 네트워크 저장소 한 달은 $3.50, 위 가정에서 5,250원이다. A5000 60시간 + CPU 가격 참고 + 네트워크 저장소의 소계는 57,285원, L4는 77,085원이다. 임시 디스크·IP·백업·세금·수수료가 추가되므로 소계를 최종 결제액으로 사용하지 않는다.

### 비용 관리 제안

GPU는 실험 시작 전에 준비하고 완료 후 불필요한 과금을 끝낸다. 프로세스 종료만으로 GPU 과금이 끝났다고 가정하지 않고 업체의 자원 해제 상태를 확인한다. 남길 저장소는 별도로 계산한다. 주기적인 지출 확인에서 누적액뿐 아니라 아직 청구되지 않은 사용량과 남은 고정 비용도 포함한다.

예상 총액이 7만 원에 도달하면 남은 실험을 재배분하고, 9만 원에 도달하면 새 GPU 실험을 보류하고 잔여 청구·정리 비용을 점검하는 운영 규칙을 제안한다. 이는 자동으로 설정된 차단 장치가 아니며, 클라우드 알림만으로 정확히 10만 원에서 과금이 멈춘다고 보장하지 않는다.

이 예산은 원격 배포 경험과 소규모 실험을 확보하면서 초기 시행착오 여유를 두려는 설계 판단이다. GPU 단가가 높거나 필요한 CPU 서버가 더 비싸면 우선 사용 시간과 환경을 조정하며 예산을 자동으로 늘리지 않는다.
