2026-09-11 현재 이 작업에서 유료 자원을 생성하거나 결제하지 않았다. Provider billing 화면은 조회하지 않았으므로 사용자 계정 전체의 지출액이나 잔액은 알 수 없다. 따라서 남은 예산도 확정하지 않는다.

## 제안한 첫 유료 실험 상한

Runpod Secure Cloud A5000의 공개 단가 `$0.27/시간`으로 계산한 1~2시간 제안이다. 실제 checkout의 리전·등급·가격·가용성·저장소·공인 IP·세금·수수료를 확인하기 전에는 구매 견적으로 쓰지 않는다. 모델과 이미지 다운로드 시간도 GPU 사용 시간에 포함된다.

| 항목 | 1시간 | 2시간 | 설명 |
|---|---:|---:|---|
| GPU compute | $0.27 / 405원 | $0.54 / 810원 | 공개 단가의 단순 계산 |
| 50GB container disk | 약 $0.007 / 10원 | 약 $0.014 / 21원 | $0.10/GB/월, 월 730시간 가정 |
| 계산 소계 | 약 $0.277 / 415원 | 약 $0.554 / 831원 | 세금·수수료·별도 IP 제외 |

Runpod 문서는 새 사용자가 `$10`부터 평가할 수 있다고 설명하며 credit은 환불되지 않는다. 따라서 실제 소비 예상 약 415~831원과 prepaid 현금 투입 `$10`(예산 환율로 15,000원)을 구분한다. 자동 충전은 켜지 않는다. Pod 생성에 필요한 최소 잔액은 선택 구성 1시간분이지만 결제 화면의 최소 충전액과 카드 조건은 checkout에서 다시 확인한다.

## 유료 실행 전 기록

- 업체, 계정 소유자, 리전, cloud 등급, 정확한 GPU와 가용성
- 시간당 compute, container/volume/network storage, 공인 IP, 세금, 결제·환전 수수료
- 충전액과 환불 조건, 자동 충전 꺼짐 여부
- 시작 시각, 수동 종료 시각, 확인 가능한 경우에만 업체 자동 종료 시각
- 100,000원 상한과 이미 확인된 다른 프로젝트 지출을 합친 예상액

하나라도 확인할 수 없거나 합계가 상한을 넘으면 자원을 만들지 않는다.

## 종료 후 기록

- 실제 시작·종료 시각과 compute 사용량
- Pod가 종료 또는 삭제된 화면 상태
- 남은 volume/network storage의 이름·크기·시간당 또는 월 비용
- billing 화면의 확정액과 아직 확정되지 않은 사용량
- 예상과 실제의 차이 및 다음 실험에 쓸 수 있는 금액
